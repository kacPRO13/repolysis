    GitHub token (optional)
    
      
    Without a token GitHub allows 60 requests per hour and 10 searches per minute, enough for a few analyses. A token raises that to 5,000 requests per hour and 30 searches per minute.
    
      
    Create a fine-grained token with no extra permissions (public repository access is enough). It stays in this browser only (localStorage) and is sent exclusively to api.github.com.
